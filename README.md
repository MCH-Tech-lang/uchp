# Символьное приведение УЧП к каноническому виду

Скрипт на Python с использованием библиотеки `SymPy` для автоматического приведения уравнений в частных производных второго порядка к каноническому виду.

## Как запустить
1. Установите зависимости: `uv pip install sympy`
2. Запустите скрипт: `python .vscode/uchp.py`
